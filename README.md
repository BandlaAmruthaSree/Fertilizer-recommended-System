# Fertilizer-recommended-System
The Fertilizer Recommendation System is a machine learning-based web application that helps farmers select the most suitable fertilizer for their crops based on soil properties, environmental conditions, and crop requirements. The system analyzes user inputs such as temperature, humidity, soil moisture, soil type, crop type, and nutrient levels (Nitrogen, Phosphorus, and Potassium) to predict the most appropriate fertilizer using a trained machine learning model.

The application is developed using Python, Flask, HTML, CSS, and Scikit-learn. The backend processes user inputs, applies a pre-trained classification model, and returns fertilizer recommendations instantly through a simple web interface. This reduces dependency on manual decision-making, minimizes fertilizer misuse, improves crop productivity, and supports sustainable farming practices.

The project follows a modular architecture where the dataset is used to train a machine learning model, the trained model is stored for prediction, and the Flask application provides an easy-to-use interface for users. The recommendation process is fast, accurate, and scalable, making it suitable for educational purposes as well as real-world agricultural decision support.

Key Features
Predicts the best fertilizer based on soil and environmental parameters.
User-friendly web interface for entering agricultural data.
Machine learning-based prediction for improved accuracy.
Reduces excessive fertilizer usage and production costs.
Supports sustainable and precision agriculture.
Modular project structure for easy maintenance and future enhancements.
