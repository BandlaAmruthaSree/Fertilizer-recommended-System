# Fertilizer Recommendation System

## Project Description

The **Fertilizer Recommendation System** is a Machine Learning-based web application that recommends the most suitable fertilizer for crops based on soil properties and environmental conditions. The system takes user inputs such as **Temperature, Humidity, Moisture, Soil Type, Crop Type, Nitrogen (N), Phosphorus (P), and Potassium (K)** and predicts the best fertilizer using a trained machine learning model.

The application is developed using **Python**, **Flask**, **Scikit-learn**, **Pandas**, **NumPy**, **HTML**, and **CSS**. A trained classification model processes the input values and provides instant fertilizer recommendations through a simple and user-friendly web interface.

The primary objective of this project is to assist farmers in making informed fertilizer decisions, improve crop productivity, reduce excessive fertilizer usage, lower farming costs, and promote sustainable agricultural practices.

## Features

- Predicts the most suitable fertilizer using Machine Learning.
- User-friendly web interface built with Flask.
- Accepts soil and environmental parameters as input.

## Machine Learning Workflow

1. Collect fertilizer recommendation dataset.
2. Preprocess and clean the data.
3. Train a Machine Learning classification model.
4. Save the trained model using Pickle.
5. Load the model in the Flask application.
6. Accept user inputs through the web interface.
7. Predict the recommended fertilizer.
8. Display the prediction to the user.
